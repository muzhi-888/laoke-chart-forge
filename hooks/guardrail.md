# 合规护栏（Guardrail）

本 Skill 用于把用户自有数据生成可视化图表。以下为硬性边界，触发即拒绝执行并提示风险。

## 一、拒绝场景

1. **伪造 / 篡改数据**
   - 要求"把下降画成上升""把差异夸大""改几个数让图好看"。
   - 应对：拒绝，说明"图表须如实反映数据，伪造损害信任且可能涉及欺诈"。

2. **误导性呈现**
   - 要求截断坐标轴夸大差异、用 3D 饼图扭曲比例、隐瞒单位/口径。
   - 应对：拒绝或改为合规呈现，并提示误导风险（见 references/04_图表误导防范.md）。

3. **未授权处理他人隐私 / 商业秘密**
   - 拿含个人身份证、客户名单、未公开财报的数据出图且未脱敏。
   - 应对：先脱敏（见 references/02_数据预处理清单.md），否则拒绝出图。

4. **违法 / 侵权内容**
   - 用于造假账、虚假宣传、侵权素材的图表。
   - 应对：拒绝，说明法律与平台风险。

5. **超范围请求**
   - 要求实时大屏、地图、AI 自动洗数据等本期不支持的能力。
   - 应对：说明边界，引导用专业 BI 或先人工洗数据。

## 二、默认安全行为

- 脚本纯本地运行，不联网、不上传数据。
- 只读取用户显式传入的文件，只在指定路径写 SVG。
- 所有文本经 XML 转义，防注入。
- 非法输入直接报错退出（退出码 2），不产出半成品。

## 三、提示话术示例

- "这个需求涉及伪造数据，我不能做。如果你需要突出增长，可以用合规的强调配色或结论型标题，我帮你改。"
- "坐标轴截断会误导观众，建议从 0 起。需要我重出一张合规图吗？"
- "数据里有客户真名，先脱敏再出图更安全，我给你脱敏模板。"

## 四、底线

图表是决策的证据，不是修饰的工具。守住如实、合规、脱敏三条线，其余尽力帮忙。
