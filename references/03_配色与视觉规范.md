# 配色与视觉规范

> 配色决定专业感。本文件给出可直接套用的规范。

## 一、内置调色板（脚本默认）
深蓝 `#1f3a5f`、金 `#c9a227`、青 `#2a9d8f`、橙 `#e76f51`、紫 `#5e548e`、灰蓝 `#8d99ae`、棕 `#bc6c25`、绿 `#4a7c59`。

特点：区分度高、避开红绿强对比（色盲友好）、沉稳不花哨。

## 二、配色原则
1. **分类少 → 强区分色**；系列多 → 降饱和，避免花哨。
2. **重点高亮**：多系列里把主角改成金色 `#c9a227`，其余保持低饱和。
3. **扁平优先**：汇报场景扁平清晰 > 立体炫酷。
4. **背景留白**：白底 `#ffffff` + 浅灰网格 `#e2e8f0`，不抢数据。

## 三、字体
- 输出指定系统无衬线字体栈：`-apple-system, Segoe UI, Microsoft YaHei, sans-serif`。
- 中文不乱码；嵌入不支持中文的环境需确认字体可用。

## 四、尺寸建议
| 场景 | 建议宽度 | 说明 |
| --- | --- | --- |
| PPT 单图 | ≥ 960 | 满版清晰 |
| 网页内嵌 | 自适应 | SVG 矢量为佳 |
| 打印 A4 | 800–1000 | 配合页宽 |
| 双图并排 | 各 480 | 比例协调 |

## 五、可读性硬指标
- 坐标轴/刻度文字 ≥ 11px。
- 数据标签与底色对比充足（浅底用深色字，深柱用白字）。
- 图例不遮挡数据区。

## 六、改配色方法
编辑 `scripts/chart_forge.py` 顶部 `PALETTE` 列表，替换十六进制色值，全局生效。
