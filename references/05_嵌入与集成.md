# 嵌入与集成

> 图做出来是为了用。本文件讲清楚 SVG 怎么落进各种场景。

## 一、SVG 是什么
- 矢量格式，放大不糊，体积小，文本可搜索。
- 标准 SVG 1.1，浏览器 / Office / 多数编辑器原生支持。

## 二、嵌入网页
```html
<!-- 方式 1：当图片 -->
<img src="趋势图.svg" alt="销售趋势" style="max-width:100%">

<!-- 方式 2：内联（可交互 hover 提示） -->
<svg ...> ... </svg>
```
内联时本脚本已为数据点/柱体加 `<title>`，鼠标悬停显示数值。

## 三、进 PPT / Word
- PowerPoint 2016+：插入 → 图片 → 选 .svg。
- 低版本 Office：先转 PNG（见下），再插入。
- 转 PNG 工具：浏览器打开 SVG 截图；或 Inkscape、ImageMagick `convert 图.svg 图.png`。

## 四、进自动化流程
- 脚本退出码：0 成功、2 失败，可被定时任务调用。
- 批量出图示例（bash）：
```bash
for f in data/*.csv; do
  python scripts/chart_forge.py --input "$f" --type bar --output "out/$(basename $f .csv).svg"
done
```
- Windows（bat）同理用 `for %%f in (data\*.csv) do ...`。

## 五、版本与归档
- 出图同时保留数据文件 + 生成命令，便于复盘与重跑。
- 汇报图建议命名：`{主题}_{日期}.svg`，如 `渠道营收_20260903.svg`。

## 六、注意事项
- 嵌入不支持中文字体的环境，预览前确认字体栈生效。
- 公网环境转 PNG 注意数据不出域，优先本地工具。
