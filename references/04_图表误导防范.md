# 图表误导防范

> 一张错的图比没有图更伤人。本文件列出常见误导手法与对策，出图前对照排查。

## 一、坐标轴陷阱
| 手法 | 问题描述 | 对策 |
| --- | --- | --- |
| 截断 Y 轴 | 不从 0 起，差异被放大 | Y 轴一律从 0 起 |
| 双 Y 轴滥用 | 量纲不同硬凑，结论易错 | 分开两张图 |
| 比例失真 | 3D 透视扭曲扇区面积 | 禁用 3D 饼图 |

## 二、数据呈现陷阱
| 手法 | 问题描述 | 对策 |
| --- | --- | --- |
|  cherry-pick | 只画好看的时间段 | 标注完整周期 |
| 单位模糊 | "120" 还是 "120 万" 不清 | 标题/轴写明单位 |
| 样本不公 | 用不同口径对比 | 统一口径再画 |
| 结论先行 | 先定结论再挑数据 | 数据驱动，结论后置 |

## 三、视觉干扰
- 网格线过粗 → 用浅灰 `#e2e8f0`。
- 配色彩虹堆 → 用有限高区分度色板。
- 一图多系列 > 4 → 拆图或高亮主线。

## 四、诚信底线
- 不伪造数据、不夸大差异、不隐瞒口径。
- 涉及他人/客户数据须脱敏并获授权。
- 图表用于辅助决策，最终判断由人负责。

## 五、发布前最后一问
"如果别人用同样的数据，能否得出相反结论？"——能，说明图有歧义或误导，回去改。
