# 图表选型指南

> 选错图型，数据再好也讲不明白。本文件是选型的权威依据。

## 一、四类核心表达意图

| 意图 | 推荐图型 | 不适用 |
| --- | --- | --- |
| 比大小 / 比多少（分类对比） | 柱状图 | 饼图（看不出精确差值） |
| 看变化 / 看趋势（随时间） | 折线图 | 饼图（无时间维度） |
| 看构成 / 看占比（整体=100%） | 饼图（≤6 类） | 超过 6 类 → 柱状 |
| 看关系 / 看分布 / 看相关性 | 散点 / 热力（本期不含） | — |

## 二、柱状图细分

- **单系列柱状**：一个指标跨分类对比（如各区域销量）。
- **分组柱状**：多指标同分类对比（如各区域"销售额/利润"并列）。分类 ≤ 5 系列为宜。
- **堆叠柱状**：看总量 + 构成（如总营收由各业务线堆叠）。
- **100% 堆叠**：只看构成比例，不看总量。

## 三、折线图细分

- **单线**：一个指标趋势。
- **多线**：多指标趋势对比，≤ 4 条。
- **X 轴必须有序**（时间/版本/序号）；无序分类请用柱状。

## 四、饼图铁律

1. 只用于"整体=100%"的构成。
2. 分类 ≤ 6；超过则合并长尾为"其他"或改用柱状。
3. 占比之和须为 100%；负值/异常值先处理。
4. 禁用 3D 饼图。

## 五、30 秒决策

```
要对比？ → 柱状
要趋势？ → 折线（X 有序）
要占比？ → 饼图（少分类）否则柱状
要关系？ → 本期不支持，换专业工具
```
