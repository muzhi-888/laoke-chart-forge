# 数据预处理清单

> 图的质量七分靠数据。出图前逐项过一遍，别把垃圾喂给脚本。

## 一、单位统一
- 同一列必须同一单位（全"万元"或全"元"），混用会让对比失真。
- 标题/轴务必标注单位。

## 二、空值处理
- 空单元格：趋势图留空会断线，建议填 0 或前值回填，并注明口径。
- 整行全空：脚本自动跳过。

## 三、异常值
- 多敲 0（12000 vs 120）、正负号错、单位错。
- 策略：标红 → 复核 → 修正或剔除，记录原因。

## 四、分类数控制
- 柱状图分类建议 ≤ 10；超过考虑聚合（如"华东/华北/其他"）。
- 饼图分类 ≤ 6。

## 五、排序
- 柱状图按数值降序，结论更直观。
- 折线图按时间/序号升序。

## 六、脱敏
- 人名、客户名、明细金额不进图。
- 用聚合值（"渠道 A"而非"张三的店"）。

## 七、自检模板
```
[ ] 单位统一且已标注
[ ] 空值已决定策略
[ ] 异常值已复核
[ ] 分类数在合理范围
[ ] 排序合理
[ ] 已脱敏
```

## 八、常见错误速查
| 错误 | 后果 | 修正 |
| --- | --- | --- |
| 万元/元混用 | 对比失真 | 统一单位 |
| 未处理空值 | 折线断裂 | 填 0/回填 |
| 含客户真名 | 泄密 | 改聚合标签 |
| 原始明细直出 | 信息过载 | 先聚合 |
